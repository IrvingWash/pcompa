# pcompa

Picture comparer

- Drag and drop images to add
- `Backpace`    to remove current image
- `Mouse wheel` to zoom
- `MMB + move`  to pan
- `RMB`         to reset panning and zooming
- `LMB`         to show current image's path, size and controls help
- `F2`          to disable fit mode
